## 免备案免掉的是什么，没免掉的是什么

实名认证管的是“你是谁”，在账号注册和下单环节核验身份证、护照或营业执照。ICP 备案管的是“这个网站能不能在中国境内公开提供访问服务”，是工信部对中国大陆机房 Web 服务的强制管理。两条线各管各的，没有因果关系。

境外节点之所以免备案，根源是机房物理位置在中国大陆境外，不在工信部 ICP 备案的管理范围内。域名解析过去就能开 80 和 443 端口，不用等审核。这跟“下单时没交身份证”没有关系。反过来也不成立：部分境外服务商会要求个人认证，但节点照样免备案。

几个具体边界值得记住：

- 未备案的域名解析到中国大陆境内服务器，80 和 443 端口会被机房系统自动拦截。
- 中国大陆服务器做公开网站，必须实名加备案。做非网站业务，比如内部数据库、API 接口、AI 模型训练、游戏后端逻辑、自动化测试，只要不绑定域名对外渲染网页，需要实名但可以不备案。这一类最容易被误解。
- 用中国大陆的 CDN、全站加速、WAF、高防 IP 这类产品时，域名仍然需要有 ICP 备案号。服务器在境外不等于加速产品也在境外。

还有一条常被忽略：免备案不等于免内容监管。机房所在地的法律照样适用，违法违规内容会被封停。任何一家正规服务商的条款里都写着这条。

## 带宽与 IP：两个下单后才发现的细节

**标称带宽不等于你能跑满。** 有第三方测评拿三家同样标 100Mbps 的香港机器做对比，从中国大陆访问的峰值速率分别是 12Mbps、38Mbps 和 71Mbps，差五倍。选套餐时要问的是“保证带宽”而不是“峰值带宽”。LightLayer 的带宽栏写的是端口上限，实际吞吐取决于线路档位和时段，这一点在它的套餐页也有类似说明。

**“不限流量”通常附带合理使用条款。** 长期跑满会被限速，行业里常见的限速区间是 1 到 5Mbps。如果你的业务是持续大流量下载，宁可买标注了固定月流量（比如 1TB）的档位，也不要赌不限流量。

**线路质量直接体现在丢包率上。** 普通国际线路晚高峰丢包率能到 3% 到 5%，页面加载要等五六秒；CN2 GIA 这类优化线路通常能压在 0.5% 以下。差价主要就花在这里，硬件配置反而差不多。

**IP 归属要看清楚。** LightLayer 的洛杉矶节点给的是原生 IPv4，台湾、香港、新加坡节点给的是非原生 IP。做本地化业务、需要 IP 归属地匹配的场景，这一条比价格重要。有测评文章列过洛杉矶 Premium 和香港 Premium 的测试 IP，下单前先 ping 一轮、跑个 traceroute，五分钟的测试比一个月的后悔便宜。
